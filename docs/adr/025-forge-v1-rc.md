# ADR 025 — Forge v1 release candidate definition

## Status

Accepted (M20)

## Decision

Forge v1 RC is declared when the 20-capability checklist is evidenced by shipped modules, the eval-suite catalog exists, and the full verification suite passes. Success still requires Forge verification — never model claims.

## Consequences

Version advances to `1.0.0-rc.1`. Hosted control plane remains a non-goal.
